# Objetivo del Proyecto: notifications-app-egx

Construir una aplicación web moderna orientada a la gestión de alertas/notificaciones utilizando Angular 21+. 
Deberá caracterizarse por implementar una **Arquitectura Limpia (Clean Architecture)** con un enfoque fuerte en Standalone Components. 

## Metas Centrales

1. **Uso de Señales (Signals)** para gestión de estado, complementado con **RxJS** para manejar eventos asíncronos de sub-sistemas mock.
2. **Accesibilidad (WCAG)** estricta, soportando navegación nativa por teclado, ARIA labels, status role, etc.
3. **Prácticas de Ingeniería**: Typescript estricto, inmutabilidad, SOLID y Clean Code.
4. **Roles / Directivas**: Control basado en el usuario (Roles) afectando la topología de la vista mediante directivas estructurales personalizadas.

Este archivo sirve como Norte del proyecto y evita divagar durante futuras implementaciones.
